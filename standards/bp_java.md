# Java 最佳实践

本文定义所有 Java 工程共同遵守的语言、数据设计、常量和字面量约束。校验与异常遵循[校验与异常最佳实践](bp_validation.md#bean-validation)。

## Java 语言

- **强制 · 基础**：使用 Java 17 编译和运行。
- **默认 · 基础**：局部变量的初始化表达式本身已清晰呈现具体类型时可以使用 `var`。
- **强制 · 基础**：必须查看被调用方法声明或依赖泛型推断才能确定局部变量类型时，使用显式类型，不得使用 `var`。
- **默认 · 基础**：能够在构造时完整确定状态、构造后不再变化，且不依赖继承、代理或 JavaBean setter 绑定的数据载体优先使用 `record`。
- **强制 · 基础**：record 的集合组件必须通过 `List.copyOf`、`Set.copyOf` 等方式防御性复制。
- **强制 · 基础**：需要继承、可变状态、框架代理、JavaBean 形态或复杂领域行为时使用普通类。
- **默认 · 基础**：优先使用 `Integer`、`Long`、`Boolean` 等包装类型；仅在明确需要基本类型默认值、性能特性或语义上不允许为空时使用基本类型。
- **建议 · 基础**：简单集合遍历可以使用 `forEach`，简单转换、过滤和映射可以使用 `Stream`，简单回调可以使用 lambda 或方法引用。
- **强制 · 基础**：复杂业务规则、嵌套条件和异常流程必须优先保证可读性，不得为使用函数式写法而增加理解成本。
- **默认 · 基础**：可能缺失的返回值及其链式处理优先使用 `Optional`。
- **强制 · 基础**：不得将 `Optional` 用作 Bean 属性或方法参数。

## 常量与字面量

### 常量

- **强制 · 基础**：取值集合固定且封闭（有限状态、类型枚举）：使用 `enum`。
- **强制 · 基础**：单一常量值需跨类复用：使用 `public static final` 常量或专门的常量类。
- **强制 · 基础**：取值可能因部署环境变化：使用配置项（配置文件/配置中心），允许有默认值。

### 字面量

- **强制 · 基础**：禁止将具有业务语义、可能被多处引用、或用于分支判断/状态标识的字符串字面量直接硬编码在业务代码中，配置文件中的默认值除外。
- **强制 · 基础**：日志文本、非业务诊断的异常提示、单元测试桩数据、正则表达式和格式化模板只有在不承载业务语义、不参与分支或状态判断且无需跨类复用时，才允许保留为字面量。
