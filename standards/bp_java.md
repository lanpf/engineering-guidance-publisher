# Java 最佳实践

本文定义所有 Java 工程共同遵守的语言、数据设计、常量和字面量约束。校验与异常遵循[校验与异常最佳实践](bp_validation.md#bean-validation)。

## Java 语言

- **强制 · 基础**：使用 Java 17 编译和运行。
- **强制 · 基础**：生产代码和测试代码不得保留未使用的类型导入（`import`）或静态导入（`import static`）；新增、修改或重构 Java 文件后必须同步检查并清理，不得以可能在未来使用为由保留。
- **强制 · 基础**：生产代码不得使用 `var`，包括局部变量、循环变量、try-with-resources 资源变量及 lambda 参数；需要声明类型时必须使用显式类型。
- **强制 · 基础**：仅测试源集允许使用 `var`，且初始化表达式必须清晰呈现具体类型；需要查看被调用方法声明或依赖泛型推断才能确定类型时，必须显式声明类型。测试源集包括单元测试、集成测试及专用测试支持源集；生产源集中的类型即使命名包含 `Test` 也不属于例外。
- **默认 · 基础**：能够在构造时完整确定状态、构造后不再变化，且不依赖继承、代理或 JavaBean setter 绑定的数据载体优先使用 `record`。
- **强制 · 基础**：需要继承、可变状态、框架代理、JavaBean 形态或复杂领域行为时使用普通类。
- **默认 · 基础**：优先使用 `Integer`、`Long`、`Boolean` 等包装类型；仅在明确需要基本类型默认值、性能特性或语义上不允许为空时使用基本类型。
- **建议 · 基础**：简单集合遍历可以使用 `forEach`，简单转换、过滤和映射可以使用 `Stream`，简单回调可以使用 lambda 或方法引用。
- **强制 · 基础**：复杂业务规则、嵌套条件和异常流程必须优先保证可读性，不得为使用函数式写法而增加理解成本。
- **强制 · 基础**：生产代码和测试代码中的 `if`、`else`、`for`（含增强 `for`）、`while` 和 `do-while` 语句体必须使用 `{}`，即使只有一条语句或语句体为空也不得省略，不得使用单独的 `;` 作为空语句体。条件链允许使用 `else if`，但每个条件分支的语句体仍必须使用 `{}`。
- **默认 · 基础**：可能缺失的返回值及其链式处理优先使用 `Optional`。
- **强制 · 基础**：不得将 `Optional` 用作 Bean 属性或方法参数。

## 集合所有权与防御性复制

- **强制 · 基础**：对象接收外部可变集合或 Map，并将其保存为自身状态或长期持有时，必须在实际保存的边界完成防御性复制，例如构造器、工厂或状态更新方法；record 与普通类均适用，不得依赖上游调用方提前复制。仅临时读取、遍历或转发集合的方法，不因接收集合而要求复制；具有明确不可变契约且容器内容不会经其他引用变化的输入可以直接复用。需要隔离原容器变化时，仅包装为不可修改视图不能替代防御性复制。明确不接管 payload 所有权的泛型信封按下述专门边界处理。
- **强制 · 基础**：明确声明不接管 payload 状态所有权的通用泛型信封（如 `Result<T>`）保存并返回原始 payload 引用，不按运行时类型猜测复制，不以未检查强转替换 payload，也不承诺快照或深层不可变；必须在公开契约中说明该边界。调用方按 payload 自身契约负责所需的快照、元素隔离和发布期间稳定性，不要求任意 `T` 一律不可变。仅供 API 使用不是豁免依据；`PageResult<T>`、`PagedList<T>` 等明确拥有集合容器的载体仍须在保存边界复制容器。
- **强制 · 基础**：保存副本的可变性必须符合对象的状态契约：record 等不可变数据载体保存不可变副本，可通过 `List.copyOf`、`Set.copyOf`、`Map.copyOf` 或等效方式实现；需要维护可变集合状态的对象保存独立的可变副本，不得将防御性复制一概等同于冻结集合。null、空容器、null 元素及具体工具的选择遵循[校验与异常最佳实践](bp_validation.md#显式检查)。
- **强制 · 基础**：容器复制不代表元素状态已隔离；契约要求隔离可变元素、嵌套容器或 Map key/value 的状态时，必须按该契约复制相应内容，或转换成具有明确不可变契约的值。不得仅凭外层容器不可修改就认定对象整体不可变，也不得对已不可变的元素机械深拷贝。

## 常量与字面量

### 常量

- **强制 · 基础**：取值集合固定且封闭（有限状态、类型枚举）：使用 `enum`。
- **强制 · 基础**：单一常量值需跨类复用：使用 `public static final` 常量或专门的常量类。
- **强制 · 基础**：取值可能因部署环境变化：使用配置项（配置文件/配置中心），允许有默认值。

### 字面量

- **强制 · 基础**：禁止将具有业务语义、已有跨类复用需求、或用于业务分支判断/状态标识的字符串字面量直接硬编码在业务代码中，配置文件中的默认值除外。稳定协议字段名遵循对应协议适配规则；纯局部技术分隔符等不承载业务或协议约定、无跨类复用需求的字面量可以就地使用，不因假设未来可能复用而强制抽取。
- **强制 · 基础**：日志文本、非业务诊断的异常提示、单元测试桩数据、正则表达式和格式化模板只有在不承载业务语义、不参与分支或状态判断且无需跨类复用时，才允许保留为字面量。
