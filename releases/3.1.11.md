# 3.1.11（2026-10-11）

## 范围

基于已发布 3.1.10（a4def8e），发布未使用 import 清理与容器校验规则。以不可变 Git 标签 `3.1.11` 发布；本次同步目标为 gateway，不包含 framework 工程的代码提交或构件发布。

## 政策变更

- `bp_java.md#Java 语言`：新增 `JAVA-IMPORT-UNUSED-001`（required / baseline），生产代码与测试代码不得保留未使用的类型导入或静态导入；新增、修改或重构文件后检查并清理。
- `bp_validation.md#显式检查`：将旧的组合选择规则拆分为 `JAVA-REQUIRE-NO-NULLS-SELECTION-001` 和 `JAVA-NULLSAFE-COPY-SELECTION-001`（均为 default / topic）。前者优先使用 `Require.noNulls` 检查元素，拒绝 null 容器、允许空容器，检查 Map 的 key 与 value；自定义异常供应器覆盖容器及元素检查。后者按目标类型选择 `NullSafe.copyToList`、`copyToSet` 或 `copyToMap`，仅在契约允许 null 归一为空容器且技术异常语义合适时使用，不重复元素检查。
- 新增 `JAVA-CONTAINER-NULL-SEMANTICS-001`（required / topic），区分 null 容器、空容器和 null 元素；不得以空容器归一化代替必须的非 null 检查，要求至少一个元素时另行保证非空。
- 退役 `JAVA-NULLSAFE-SELECTION-001`，保留其完整发布文本、分类及替代关系于 `3.1.11.rules.json`，不重新使用该 ID。原未发布校验草稿整合进本发布记录，不修改既有发布历史。
