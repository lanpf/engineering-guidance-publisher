# 3.1.12（草稿，整合至 3.1.13）

## 范围

基于已发布 3.1.11，完善集合所有权与防御性复制约束。本文件保留草稿阶段的规则拆分与退役记录；这些变更统一纳入 3.1.13 发布，3.1.12 不单独发布或创建 Git 标签。实际发布清单与验证结果以 `3.1.13.md`、`3.1.13.rules.json` 及本次交付报告为准。

## 政策变更

`bp_java.md#集合所有权与防御性复制` 是唯一权威定义，分层与校验文档仅引用，standards 索引补充该范围。

- `JAVA-COLLECTION-OWNERSHIP-001`：保存外部可变集合或 Map 的对象在实际保存边界复制，不依赖上游；临时读取、遍历、转发无需复制，契约明确不可变的输入允许复用。仅使用不可修改视图不能隔离原容器变化。
- `JAVA-COLLECTION-COPY-MUTABILITY-001`：按状态契约选择独立可变副本或不可变副本；record 等不可变数据载体保持不可变容器。null/empty 和具体工具选择回引校验文档。
- `JAVA-COLLECTION-ELEMENT-ISOLATION-001`：容器复制不是元素隔离；仅在契约要求时处理可变元素、嵌套容器与 Map key/value，不机械深拷贝已不可变值。

三条新增规则均为 required / baseline，分别对应保存责任、副本可变性和元素隔离。退役旧 record 专属规则 `JAVA-RECORD-002`，保留旧文本、分类与替代关系在 `3.1.12.rules.json`，不复用其 ID。

## Consumer 与工作流

代码合规性变更仅涉及 `develop-service` 的 `java-language.md`：新增 3 条、修订 0 条、退役 1 条。Skill 名称、scope、blueprint 和引用文件路由不变；既有基础引用内新增来源可追踪的集合规则章节。
