# 3.1.9（2026-10-09）

## 范围

基于 3.1.8（427e838）统一政策粒度：独立决策与不变量分别声明，条件、正反表述和例外随规则保留；名称、方法、日志级别和错误码映射采用选择表；测试覆盖清单保持完整场景粒度。Skill 名称、scope、引用文件与路由保持不变。

## 变更性质

- 新增 161 个规则 ID，退役 89 个复合或重复 ID，原 ID 修订 2 个；新增 ID 多数承接原有约束，不代表同等数量的新政策。
- 同步工作区已更新的 `Require.valid`、参数非空检查与 `NullSafe` 规则；当前发布表示统一使用 `Require.valid`。
- 补齐源文档既有的请求入口校验组规则 `JAVA-VALIDATION-ENTRY-GROUP-001`，保持 required/topic。
- 谓词输入纯度与跨变量守卫分开；跨变量失败按业务/技术语义分类，不再一律认定为技术性前置条件。
- 采用 Bean Validation 后保证实际触发、测试辅助代码隔离等执行要求为 required；工具/record 偏好与立即获取锁的策略独立为 default。
- `TEST-SELF-CONTAINED-001` 从 catalog 的 required 对齐源文档既有的 default。
- 复杂规则正式拆分时退役原复合 ID 并记录替代关系，不将旧 ID 重用于更窄的新含义。
- 历史版本中的旧方法名称作为不可变的原始政策记录保留；当前标准、catalog 和生成引用不再使用旧调用。

## Consumer 变更

- `develop-service`：新增 125，修订 1，退役 72。
- `develop-distributed`：新增 24，修订 0，退役 11。
- `develop-compensation`：新增 6，修订 0，退役 3。
